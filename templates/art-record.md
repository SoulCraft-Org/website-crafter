# Art record

One row per picture, video or 3D model a page shows. Paste the rows for a change into its pull request (the [pull request template](pull-request.md) has the table), and keep the full record in your site repo, such as `docs/art-record.md`. The media map's Record step scores pull requests that carry it.

| File | Page | Model | Prompt | Style block | Seed | Licence | Read on | Approved by |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `public/art/hero.avif` | `/` | Model and version | Prompt, or its file | v1 | 1234 | The model's licence | YYYY-MM-DD | The owner |

| Column | Write |
| --- | --- |
| File | The asset as it ships, after it was sized and compressed |
| Model | The exact model and version, such as the one a prompting skill names |
| Prompt | The prompt itself, or a committed file that holds it. A JSON caption counts |
| Style block | Which version of your site's style block it used, so a later render matches |
| Seed | The seed, so the picture can be made again |
| Licence | The model's terms for your use, and where you read them |
| Read on | The day you read that licence |
| Approved by | Who said yes before any spend on the next step, such as 3D or video from this picture |

Never record a person's likeness without their consent, and never a character someone else owns.
